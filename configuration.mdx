### GitHub Integration

<Steps>
  <Step title="Connect Repository" icon="git-branch">
    Authorize Qwin Q to access your GitHub account.
    
    <CodeGroup tabs="Webhook,Manual">
      ```bash
      # Set up webhook for automatic sync
      curl -X POST https://api.github.com/repos/owner/repo/hooks \
        -H "Authorization: token YOUR_TOKEN" \
        -d '{"config":{"url":"https://qwinq.com/webhook","content_type":"json"}}'
      ```
      ```bash
      # Manual sync command
      qwinq sync --repo owner/repo
      ```
    </CodeGroup>
  </Step>
  <Step title="Configure Sync Rules" icon="settings">
    Define which branches and files to sync.
    
    Set up automatic publishing on merge to main branch.
  </Step>
</Steps>

## Environment Variables

Use environment variables for sensitive configuration.

<CodeGroup tabs=".env,Config File">
  ```bash
  # Environment variables
  QWINQ_API_KEY=your_api_key
  QWINQ_DATABASE_URL=postgresql://...
  QWINQ_REDIS_URL=redis://...
  ```
  ```json
  {
    "api_key": "your_api_key",
    "database": {
      "url": "postgresql://..."
    },
    "redis": {
      "url": "redis://..."
    }
  }
  ```
</CodeGroup>
