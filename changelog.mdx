## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added advanced search with filters and facets
- Introduced dark mode support across all interfaces
- Implemented real-time collaborative editing
- Added support for custom domains with SSL certificates

## Improvements

- Enhanced API performance with response caching
- Improved mobile responsiveness for all pages
- Updated editor with syntax highlighting for more languages
- Streamlined onboarding process for new users

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- Complete redesign of the user interface
- Introduced modular architecture for better scalability
- Added comprehensive API for third-party integrations
- Implemented advanced permission system with roles

## Breaking Changes

- API endpoints have been restructured - see migration guide
- Authentication flow updated - OAuth providers need reconfiguration
- Custom themes require updates for new CSS structure

</Update>

<Update label="2024-08-10" description="v1.5.0" tags={["feature", "bugfix"]}>

- Added webhook support for real-time notifications
- Introduced version control integration with Git
- Implemented PDF export functionality
- Added support for embedded media and diagrams

## Bug Fixes

- Fixed issue with long document loading times
- Resolved authentication problems with certain OAuth providers
- Corrected display issues in mobile browsers
- Fixed memory leaks in the editor component

</Update>
